# Ghost Intel 98 — v3.72.7

**Maintainer metadata removed from the packaged application.**

No functional changes. Everything in v3.72.6 behaves identically.

Earlier builds embedded the maintainer's name and email address in the application's own metadata, which meant the packaged app carried it inside the installer. The project is now attributed to **Obsidian Circuit**, and this is the first build produced from the corrected source — so the shipped application no longer contains an individual's identity.

This release is also the first published by the project's automation rather than by a person.

## Install

Windows NSIS installer — `GhostIntel98-Setup-3.72.7.exe` (per-user, no admin; unsigned → **More info → Run anyway**). Installs over the previous build in place.

- **SHA-256:** `__SHA256__`
- **Size:** `__SIZE__`

Confirm **Settings ▸ About** reads **3.72.7**.
