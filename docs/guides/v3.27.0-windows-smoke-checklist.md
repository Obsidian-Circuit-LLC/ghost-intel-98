# Ghost Intel 98 v3.27.0 — Windows smoke checklist

Quick pass on real Windows hardware. Each item is one click and one thing to look for. If anything
below **doesn't** happen, screenshot it and send it — that's a bug, not you.

## First launch (the migration)
- [ ] App boots to the desktop — no blank teal screen, no error dialog.
- [ ] Your existing cases are all still there (My Cases).
- [ ] If you had SOCMINT or X data before: open SOCMINT / X — your harvested items are still reachable (now under their own Cases sidebar).
- [ ] Optional peek: `%APPDATA%\Ghost Intel 98\GhostAccess98\scraping-cases\backup-pre-v3.27.0\` exists and has your old files (that's the safety backup — you don't need to touch it).

## Crash-safety (W1) — the teal-screen bug
- [ ] Open the **OSINT Toolkit** → click **Host Info**. It opens a host/IP entry box. **No crash.**
- [ ] Toolkit → **News**. It opens the news viewer. **No crash.**
- [ ] Toolkit → **Camera**. It opens a "paste stream URL / launch from EyeSpy" entry. **No crash.**

## OSINT consolidation (W5)
- [ ] Desktop is decluttered — Searchlight / SOCMINT icons are gone; the **OSINT Toolkit** icon is still there.
- [ ] Bottom-left **Access** menu → hover **OSINT Toolkit** → a one-hop submenu fans out with the tools grouped (Social Media / Geospatial / Identity / Network-Recon). **The whole list is on-screen** (nothing cut off the bottom).
- [ ] Click a few tools from the flyout — each opens.
- [ ] The OSINT Toolkit window opens compact (folder-sized), not huge.

## CCTV host-resolution (W2)
- [ ] Settings → GeoINT: there's a **"Resolve camera hosts over Tor"** toggle (on by default), separate from "Route CCTV streams through Tor."
- [ ] In GeoINT, open a camera's **Host resolution** with Tor not yet up: it shows **"needs Tor / bootstrapping"** and does **not** spin forever.
- [ ] Turn the resolve toggle **off**: host resolution says it's turned off and does not run.

## GhostScrape (W3)
- [ ] With X Intel cookies added + X network enabled: run a scrape. It captures, or shows a clear "session may be invalid — re-add cookies" message (not a silent empty result).
- [ ] (If you can) start two scrapes for different accounts close together — neither logs the other out / mixes results.

## Scraping cases (W4)
- [ ] SOCMINT shows its **own** Cases sidebar — **not** your investigation cases. "Add Case" makes a new one; Delete removes it.
- [ ] X / GhostScrape show their own Cases sidebar the same way.
- [ ] "Import into a main case" pulls a scraping case's results into one of your investigation cases.

## Searchlight (W7)
- [ ] Searchlight → Relationship Graph: **Clear Graph** asks to confirm, then wipes the graph (this case only). Import Results rebuilds it.

## Installer (W6) — run the installer itself
- [ ] The installer shows a checkbox **"Remove data and settings from a previous installation"** — **unchecked** by default. Leaving it unchecked installs normally and keeps your data.
- [ ] (Only if you want a clean slate) checking it removes the previous `%APPDATA%` data.

---
Anything that crashes, spins forever, shows an error, or looks off → screenshot + send. Green across the
board means v3.27.0 is solid on your box.
