# Ghost Intel 98 v3.31.0 — Windows smoke checklist

Quick pass on real Windows hardware. Each item is one click and one thing to look for. If anything
below **doesn't** happen, screenshot it and send it — that's a bug, not you.

## First launch
- [ ] App boots to the desktop — no blank teal screen, no error dialog.
- [ ] Your existing cases, memory, and settings are all still there (nothing reset).

## Multi-engine web search (feature 1)
- [ ] Open **Q** (the assistant). In the chat toolbar, next to the **Web (Tor)** checkbox, there's a small **engine dropdown** with **DuckDuckGo** and **SearXNG** (each marked "· Tor").
- [ ] Turn **Web (Tor)** on, pick **DuckDuckGo**, ask something current ("who won the latest F1 race"). Q shows a "🔍 searching **DuckDuckGo** over Tor…" line, then answers with source URLs.
- [ ] Switch the dropdown to **SearXNG**, ask another question. The searching line now names **SearXNG**, and you still get sourced results. (If Tor is slow it may say why — "couldn't reach … over Tor" — that's a Tor-reachability message, not a crash.)

## Clickable links in Q's replies (feature 2)
- [ ] In an answer with a **"Sources used"** list (or any URL), the links are **clickable** (underlined/blue), not plain text.
- [ ] Click one: a **one-time notice** warns that opening it uses your real IP (clearnet), asking you to confirm. Confirm once.
- [ ] The link opens **outside** the app (your browser / bundled Firefox), and the app itself does **not** navigate away. After the one-time confirm, later links open without re-asking.

## Voice input, now bundled (feature 4)
- [ ] Open Q. The old **"🎙 Voice input needs a Vosk model in resources/vosk/"** banner is **gone**.
- [ ] There's a **🎤 Talk to Q** button. Click it → it flips to **🔴 Listening — tap to stop** and asks for the mic.
- [ ] Say a sentence. Your words appear as text / Q responds. Tap again to stop. (First use may pause a second while the model loads.)

## X / Twitter collector sessions (feature 3)
- [ ] Settings → **X**: adding an account asks for **`auth_token` + `ct0` together** (one session), with a **local label**. The one clearnet gate has a **first-time consent modal** about real-IP exposure.
- [ ] Add a session, then click **Test session** → it reports **✓ valid, @handle** or **✗ invalid/expired** (not a silent nothing).
- [ ] In the X Collector, the account is picked from a **dropdown by label** (showing its status).

## Investigation cockpit (feature 5)
- [ ] Open a case (Cases → open one). In the case detail buttons there's a new **"Open investigation…"** (next to Open Notepad / Open whiteboard).
- [ ] Click it: the **investigation cockpit** opens — a dark entity-graph canvas with an **Add node** control, and a docked **Run / Report** panel on the right. **No "Invalid caseId" error.**
- [ ] Add a node (e.g. an email). It appears on the graph. The **Report** tab generates an INTELREPORT you can **export to PDF**.
- [ ] The **Run** tab shows a calm **"checking for the reasoning pack…" / unavailable** state — that's expected in this build (the automated-run engine is a forthcoming add-on), not an error.
- [ ] Sanity: opening **Investigation Graph** from the OSINT Access menu (with no case) shows a short **"Open an investigation from a case"** hint — **not** an error.

## Carry-forward (nothing regressed)
- [ ] Searchlight username sweep still runs; GeoINT map still loads; EyeSpy still lists cameras; SOCMINT/GhostScrape still open.
- [ ] Memory: "➕ Add to memory" still works and Mind's Eye still renders.
