# v3.43.0 — News window tighten + Number Muncher top-tab modes — Design

**Date:** 2026-07-11
**Origin:** GhostExodus field feedback on v3.42.0 (screenshots + a mockup).
**Repo:** `/dcs98` (core). Target **v3.43.0**. One batch, two independent items.

## Feedback + operator decisions

1. **News window** — "remove the scroll bar on the right, and rearrange the menu area to reduce the amount of empty space, and by extension reduce the window size." The **mockup (image 1)** is the clean GB News pop-out: compact controls at top, video filling the rest, **no right scrollbar**. Scope confirmed = **News window only** for this item.
2. **Number Muncher** — separately, "reduce to about this size." Menu rearrangement confirmed = **modes as a top tab strip** (not the left rail), and shrink the window.

## Charter

- Pure client-side layout. No new dependency, no egress, no engine/behavior change. The GeoINT `networkEnabled` gate and every calculator engine are untouched.

## Part 1 — News window (NewsViewModule)

**Root cause of the scrollbar:** the shared window wrapper `.ga98-window-shell .window-body { flex: 1; overflow: auto; }` is global (other modules depend on it). The News module content overflows it slightly, tripping that `overflow: auto` into a right scrollbar. **Do NOT change the global rule.**

**Changes (scoped to NewsViewModule / its controls):**
- The `NewsViewModule` root `<div>` is a full-height flex column that **clips its own overflow** (`overflow: hidden`) so nothing legitimately scrolls — the video already fills `flex: 1; minHeight: 0`, so clipping removes the sub-pixel overflow that triggers the window scrollbar.
- Tighten the control ("menu") area to remove empty space: reduce the Stream-row `marginBottom` and the Add-stream-row `marginTop` in `NewsFeedControls` (6px → ~4px), and keep the label bar thin. Result matches the mockup's compact top.
- The default window size (640×480) stays — the mockup IS a ~640×480 pop-out; the fix is the scrollbar + spacing, not the window dimensions.

**Shared-control caveat:** `NewsFeedControls` is rendered by BOTH the standalone News window AND the GeoINT `LiveNewsPanel`. Tightening its spacing affects both — acceptable (both get slightly tighter). The v3.42.0 pop-out (⧉) button + the v3.42.0 `.ga98-livenews` fieldset rule stay intact.

## Part 2 — Number Muncher (top-tab modes + smaller)

**Current:** `.ga98-calc { grid: auto 1fr }` (left mode rail | main). The rail leaves a large empty grey area below the 7 buttons, and the 380×580 window is taller than the content needs.

**Changes:**
- `.ga98-calc` becomes a **flex column**: a **top mode tab strip** (the 7 modes as a wrapping row of tabs) then the existing main area (topbar/display, mem-row, keypad, statusbar). The left rail is gone, so no empty side column.
- Mode buttons restyle from a vertical rail to a horizontal wrapping tab row (`.ga98-calc-tabs` / reuse `.ga98-calc-mode` with row layout). Active-tab styling unchanged (blue).
- Registration `defaultWidth: 380 → 320`, `defaultHeight: 580 → 450` — fits the content, kills the empty space and the oversize.
- History drawer still overlays `.ga98-calc-main` (unchanged). Memory-scope rule (Standard/Scientific only) unchanged. All 7 mode keypads unchanged.

- News window resize/default-size changes beyond the scrollbar/spacing fix.
