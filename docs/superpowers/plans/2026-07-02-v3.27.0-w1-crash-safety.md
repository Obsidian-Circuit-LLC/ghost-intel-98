# W1 — Crash safety: module error boundary + Hosts/News/Camera standalone entries — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: superpowers:subagent-driven-development. Steps use checkbox (`- [ ]`) syntax. Implementers run SEQUENTIALLY on the shared tree — never parallel.

**Goal:** Stop the OSINT Toolkit / Access-menu from crashing the whole app when Hosts, News, or Camera are opened without a `stream`, and permanently contain the crash class.

**Architecture:** Add a module-level React error boundary in `ModuleHost` (category fix), then give Host Info / News / Camera real "no-stream" standalone entry UIs so their Toolkit/flyout tiles are functional rather than crash-prone.

**Tech Stack:** Electron + React + TypeScript (strict), Vitest (`pnpm test`), Win98-styled renderer.

### Task 1: Module-level error boundary in ModuleHost

**Files:**
- Create: `src/renderer/shell/ModuleErrorBoundary.tsx` (a class component modeled on `geoint/MapErrorBoundary.tsx`)
- Modify: `src/renderer/shell/ModuleHost.tsx` (wrap the rendered module component)
- Test: `test/module-error-boundary.test.tsx`

**Interfaces:**
- Produces: `<ModuleErrorBoundary moduleKey={string}>{children}</ModuleErrorBoundary>` — catches render/mount throws from `children`, renders a contained Win98 panel ("This tool failed to load", the error message, a Close/dismiss affordance) instead of rethrowing. Resets its error state when `moduleKey` changes (so reopening a different module in the same host slot recovers).

- [ ] **Step 1: Write the failing test.** A test-only child component that throws during render, mounted inside `ModuleErrorBoundary`, renders the fallback panel text (e.g. "failed to load") and does NOT propagate the throw (the surrounding tree stays mounted). Also assert a non-throwing child renders normally (boundary is transparent on the happy path).
- [ ] **Step 2: Run it, verify it fails** (`pnpm test module-error-boundary`) — fails because the component doesn't exist.
- [ ] **Step 3: Implement** `ModuleErrorBoundary` (class component with `getDerivedStateFromError`/`componentDidCatch`, `console.warn` the error main-nothing/no telemetry, contained fallback panel styled with existing `ga98-*` classes). Wrap `ModuleHost.tsx:25`'s `<C spec={spec}/>` in it, keyed by the module key so a new module resets the boundary.
- [ ] **Step 4: Run tests, verify green.**
- [ ] **Step 5: Commit** (`feat(shell): contain module render crashes with a module error boundary`).
