# QUIET AMETHYST Theme — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Ship a complete two-tier theme map + registry for Ghost Intel 98 and deliver **QUIET AMETHYST**, a fully-dark midnight-purple theme where every reachable surface — shell chrome, standard 98.css windows/controls, and module interiors — renders dark with legible text and no light island, while classic stays byte-for-byte unchanged.

**Architecture:** Copy the proven `data-ga98-intensity` mechanism: a `data-ga98-theme` attribute on `<html>` from `AppSettings.themeName`, base `:root` = classic values for every token, `:root[data-ga98-theme='amethyst']` overrides only skinnable palette tokens; fixed semantic/honesty tokens live only in base `:root`. Because the bundled **98.css library hardcodes all control colours with no variables**, the theme also ships a dark 98.css override sheet gated by the same attribute, plus per-module resolution of ~179 hardcoded colour conflicts.

**Tech Stack:** Electron + React 18 (`createRoot`+`act`, no @testing-library) + TypeScript; Vitest (jsdom for panels, node for services); CSS (`theme.css` + `98.overrides.css` over the `98.css` npm lib); headless computed-style checks via playwright-core Chrome.

## Global Constraints

- No new network egress, telemetry, or dependency. A theme is CSS + one settings scalar.
- Commit author `onna-bugeisha-dev-team <dev@onna-bugeisha.org>`, `git -c user.name=… -c user.email=… commit --no-verify`. **No AI-identity trailers** (no Co-Authored-By / Signed-off-by / Claude-Session / Generated-with). Explicit-path `git add <paths>` only — never `-A`/`.`.
- **Implementers commit ONLY on the feature branch** `feat/quiet-amethyst-theme`. The controller merges to main.
- Never stage `resources/satellites/active-snapshot.tle`, `native/dcs98-confine/Cargo.lock`, `docs/superpowers/ideation/`, `resources/local-ai/`, or `.superpowers/` scratch.
- **Two-tier invariant (charter-critical):** fixed tokens `--ga98-status-error|success|warning|info` and `--ga98-unverified` are defined ONLY in base `:root` and appear in NO theme override block. A skin must never recolour/hide a status or honesty colour.
- **Classic parity:** every new token's classic value equals the exact colour it replaces; classic renders identically to pre-change (except the deliberate unification of ad-hoc status colours to the fixed tier).
- **Locked amethyst palette (skinnable):** desktop-bg `#0c0a12`, surface/`--ga98-grey` `#1a1822`, `--ga98-shadow-light` `#2c2938`, `--ga98-shadow-dark` `#0e0c14`, `--ga98-shadow-deep` `#000000`, `--ga98-blue`(titlebar start) `#241a33`, `--ga98-titlebar-to` `#3a2a52`, `--ga98-titlebar-text` `#efeaff`, `--ga98-accent` `#9d6bff`, `--ga98-text` `#cfc9dd`, `--ga98-text-dim` `#8a86a0`.
- **Fixed tier (all themes, one value each):** `--ga98-status-error #e5484d`, `--ga98-status-success #30a46c`, `--ga98-status-warning #d98a00`, `--ga98-status-info #4c8dff`, `--ga98-unverified #d98a00`. Final values pass the contrast gate on both `#c0c0c0` and `#1a1822`.
- **CSS/layout tests** use the headless computed-style harness and MUST mount within `.ga98-window-shell > .window > .window-body` (the `.window{height:100%}` cascade trap only manifests with the shell present). jsdom is blind to CSS cascade — never assert colour in jsdom.
- Test harness: React 18 `createRoot`+`act`; panel tests mock `window.api`; main-service tests `vi.mock('../src/main/storage/json-fs', …)` + `vi.stubGlobal('fetch', …)`. Typecheck covers `src/**` only (not `test/**`).
- `themeName` label is `QUIET AMETHYST`, slug `amethyst`, attribute value `amethyst`; classic slug `classic`.
