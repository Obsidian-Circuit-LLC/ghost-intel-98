# W4 — Per-tool scraping case stores + migration + import-to-case — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: superpowers:subagent-driven-development. Steps use checkbox (`- [ ]`). Implementers run SEQUENTIALLY on the shared tree.

**Goal:** Give SOCMINT and X (X Intel + GhostScrape) their OWN encrypted case stores, separate from the investigator's main cases, each with a left-hand Cases sidebar; migrate existing SOCMINT/X items out of the main cases (with a backup); and let results be imported into a main case.

**Architecture:** A generic scraping-case store factory instantiated per namespace (`socmint`, `x`), persisting through secure-fs into a separate `scraping-cases/<ns>/` root. SOCMINT/X item persistence is repointed via the stores' existing injectable path resolvers. A one-time, marker-guarded, idempotent, reversible migration splits existing items (X-platform → x store, rest → socmint store) and backs up the originals. New IPC namespace + three renderer sidebars + an import-to-main-case action.

**Tech Stack:** Electron main (TS strict), React renderer, Vitest, secure-fs (encrypted at rest).

## Global Constraints

- **Encrypt at rest:** all scraping-case data goes through `secureReadFile`/`secureWriteFile` (never the plain bypass).
- **Determinism (migration is correctness-critical):** the migration is deterministic + idempotent (re-run after the marker is a no-op); which store an item lands in is a pure function of the item (`platform:'x'` → x store, else socmint), not iteration order or a clock.
- **Reversible:** the migration COPIES to the new store + writes a backup of the originals BEFORE removing them from the main case; a backup marker allows recovery.
- **X clearnet quarantine:** changes under `src/main/x/**` must not import bgconn/Tor/etc.; deps stay injected.
- Commit as `onna-bugeisha-dev-team <dev@onna-bugeisha.org>`; NEVER any AI-identity trailer. Do NOT stage `pnpm-lock.yaml`, `resources/satellites/active-snapshot.tle`, `native/dcs98-confine/Cargo.lock`.
- `pnpm typecheck` clean; suite green (2,486 baseline on main after W6). No new egress, no telemetry.
- The investigator's operator decision: **separate per tool** (socmint store + x store; X Intel and GhostScrape share the x store).
