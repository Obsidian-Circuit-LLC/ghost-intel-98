# W6 — Installer: opt-in "remove previous instance data" checkbox — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: superpowers:subagent-driven-development. Steps use checkbox (`- [ ]`). Implementers run SEQUENTIALLY.

**Goal:** Add a NON-mandatory, default-unchecked installer checkbox that, when ticked, removes a previous installation's `%APPDATA%` data/config before install. Never touches `$INSTDIR` (electron-builder manages that on upgrade).

**Architecture:** Wire electron-builder's `nsis.include` to a new custom NSIS script that adds an nsDialogs checkbox after the install-dir page (`customPageAfterChangeDir`) and, in `customInstall`, conditionally `RMDir /r`s the app's `%APPDATA%` dirs. No runtime app code changes.

**Tech Stack:** electron-builder NSIS (config in `package.json`), a `.nsh` script, Vitest (static-content guard only — NSIS itself isn't unit-testable; a full install is verified in W8 QA).
