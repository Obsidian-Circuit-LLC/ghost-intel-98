# W2 — CCTV host-resolution: kill the Tor hang, keep Tor-only, explicit toggle — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: superpowers:subagent-driven-development. Steps use checkbox (`- [ ]`). Implementers run SEQUENTIALLY on the shared tree.

**Goal:** Host resolution must never hang on Tor bootstrap, must stay Tor-only (never clearnet), and must honor an explicit on/off setting instead of silently riding the unrelated CCTV-stream checkbox.

**Architecture:** Fast-fail the plugin-egress Tor path when it isn't bootstrapped (return a partial result fast instead of blocking on `tor.start()`), add a `geoint.cctvResolveHosts` setting (default on) that disables resolution when off (never falls back to clearnet), and fix the renderer states + copy.

**Tech Stack:** Electron main + React renderer, TS strict, Vitest.
