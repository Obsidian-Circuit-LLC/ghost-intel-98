# Ghost Intel 98 — v3.71.2

**Jukebox: a Purge button to wipe the whole library.**

The Jukebox (mp3 player) gets a **Purge…** button in its library toolbar. Click it and it asks first —

> *Erase the ENTIRE Jukebox library — every imported track, remembered music folder, and saved radio station? This cannot be undone.*

— and only on confirm does it clear everything: all indexed tracks, every remembered music folder, and every saved radio station. Playback stops and the play queue empties. Decline the prompt and nothing is touched. The library store is encrypted at rest, same as before.

## Install

Windows NSIS installer — `GhostIntel98-Setup-3.71.2.exe` (per-user, no admin; unsigned → **More info → Run anyway**). Installs over the previous build in place.
